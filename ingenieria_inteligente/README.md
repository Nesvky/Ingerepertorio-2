# Ingeniería Inteligente — primera versión
Web académica multipágina construida con HTML5, CSS3, JavaScript y Bootstrap 5.3.

## Archivos
- index.html: portada y navegación.
- fundamentos.html: conceptos y proceso interactivo.
- aplicaciones.html: ejemplos por disciplina y modales.
- control-sat.html: caso de Medellín y cifras del piloto 2025.
- conclusion.html: oportunidades, límites y cuestionario.
- css/styles.css: identidad visual.
- js/main.js: interacciones.

## Uso
Descomprime el ZIP y abre `index.html` en el navegador. Bootstrap, iconos y fuentes se cargan desde CDN, así que necesitas internet para verlos correctamente. No requiere servidor ni base de datos.

## Pendiente
Reemplazar bloques gráficos por fotografías propias o con licencia adecuada; añadir integrantes, curso, docente y bibliografía final.
